# Настройка Ubiquiti UniFi

## Требования
- Контроллер UniFi (локальный или облачный)
- Точка доступа с гостевой SSID

## Шаги
1. Войдите в контроллер UniFi.
2. Перейдите в **Settings** → **Profiles** → **RADIUS**.
3. Создайте новый RADIUS-профиль:
   - **IP address** – IP вашего сервера с платформой.
   - **Port** – 1812 (авторизация), 1813 (аккаунтинг).
   - **Secret** – секретный ключ, указанный при регистрации NAS.
4. Перейдите в **Settings** → **Wireless Networks** и выберите нужную SSID.
5. В разделе **Security** выберите **RADIUS** и укажите созданный профиль.
6. Примените изменения.

## Управление сессиями
В текущей версии платформы принудительное завершение сессий через API UniFi не реализовано, но мониторинг статуса устройства осуществляется через проверку порта (по умолчанию 8443).
