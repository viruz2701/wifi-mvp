# Настройка MikroTik (RouterOS) для работы с WiFi Auth Platform

## 1. Предварительные требования
- RouterOS версии 6.x или 7.x.
- Настроенный интерфейс для гостевой сети (например, bridge с DHCP-сервером).
- Доступ к маршрутизатору через WinBox, WebFig или SSH.

## 2. Настройка Hotspot
1. Перейдите в меню `IP` -> `Hotspot`.
2. Нажмите кнопку `Hotspot Setup` и выберите интерфейс, на котором будет работать гостевой доступ (например, `bridge_guest`).
3. Настройте параметры сети:
   - Адрес пула: `192.168.100.2-192.168.100.254`
   - Маска: `255.255.255.0`
   - Шлюз: `192.168.100.1`
   - DNS-серверы: оставьте по умолчанию или укажите свои.
4. Укажите имя сервера (например, `hotspot1`).
5. В настройках адресации выберите `masquerade` и настройте NAT для выхода в интернет.
6. Настройте SSL-сертификат (опционально, но рекомендуется).

## 3. Настройка RADIUS-клиента
Для интеграции с платформой необходимо настроить RADIUS-клиента.

1. Перейдите в `Radius` (меню `Radius`).
2. Нажмите `+` и добавьте сервер RADIUS:
   - **Address**: IP-адрес вашего сервера с платформой (например, `10.0.0.10`)
   - **Secret**: общий секретный ключ (должен совпадать с тем, что указан в настройках NAS-устройства на платформе)
   - **Service**: выберите `hotspot`
   - **Ports**: оставьте стандартные (1812 для авторизации, 1813 для аккаунтинга)
3. Включите опции `Accounting` и `Authentication`.

## 4. Настройка Hotspot для работы с внешним порталом
По умолчанию Hotspot использует встроенную страницу авторизации. Чтобы перенаправлять пользователей на ваш портал, измените настройки Hotspot.

1. Перейдите в `IP` -> `Hotspot` -> вкладка `Server Profiles`.
2. Выберите созданный профиль (обычно `hsprof1`) или создайте новый.
3. В поле **HTML Directory** укажите путь к локальной папке с файлами портала (необязательно, если используется внешний портал).
4. Включите опцию **Use Radius** для авторизации.
5. В поле **Login By** выберите `cookie` и `mac-address` (можно оставить по умолчанию).
6. В разделе **Radius** убедитесь, что сервер добавлен.

**Важно:** Если вы хотите, чтобы MikroTik перенаправлял пользователей на внешний портал, можно использовать скрипт или настроить **Walled Garden**. Но для упрощения лучше оставить стандартную страницу, которая будет отправлять данные на RADIUS-сервер.

## 5. Создание пользователя для API (опционально)
Для удалённого управления устройством через API создайте отдельного пользователя с правами на чтение/запись:
/user add name=wifiapi password=strongpass group=full

## 6. Проверка подключения
- Убедитесь, что устройство добавлено в платформу как NAS-устройство (тип `mikrotik`).
- Проверьте, что RADIUS-запросы приходят на сервер (логи сервера).
- Подключитесь к гостевой сети, откройте браузер – должна появиться страница авторизации (встроенная или внешняя). После ввода номера телефона и подтверждения кода доступ должен открыться.

## 7. Дополнительные настройки
- **Ограничение скорости**: можно настроить в профиле пользователя RADIUS (атрибуты `WISPr-Bandwidth-Max-Up/Down`).
- **Блокировка пользователей**: через платформу или直接在 RouterOS (например, через firewall).

## 8. Устранение неполадок
- Проверьте логи RADIUS: `/radius monitor`.
- Убедитесь, что секретный ключ совпадает.
- Проверьте доступность сервера RADIUS по сети (ping, порты).
