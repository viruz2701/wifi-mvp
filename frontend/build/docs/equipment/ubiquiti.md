# Настройка Ubiquiti UniFi

## Требования
- Контроллер UniFi (локальный или облачный)
- Точка доступа с гостевой SSID

## Шаги
1. Войдите в контроллер UniFi.
2. Перейдите в **Settings** → **Profiles** → **RADIUS**.
3. Создайте новый RADIUS-профиль:
   - **IP address** – IP вашего сервера с платформой.
   - **Port** – 1812 (авторизация), 1813 (аккаунтинг).
   - **Secret** – секретный ключ, указанный при регистрации NAS.
4. Перейдите в **Settings** → **Wireless Networks** и выберите нужную SSID.
5. В разделе **Security** выберите **RADIUS** и укажите созданный профиль.
6. Примените изменения.

## Управление сессиями
В текущей версии платформы принудительное завершение сессий через API UniFi не реализовано, но мониторинг статуса устройства осуществляется через проверку порта (по умолчанию 8443).



Настройка Ubiquiti UniFi с RADIUS
3.1. Создание RADIUS-профиля в контроллере
Войдите в контроллер UniFi.

Перейдите в Settings → Profiles → RADIUS.

Нажмите Create New RADIUS Profile.

Заполните:

Name: например, "WiFiAuth"

IP address: IP вашего сервера (или WireGuard IP, если используется туннель)

Port: 1812

Accounting Port: 1813

Secret: секретный ключ, указанный при регистрации NAS

Сохраните.

3.2. Применение профиля к SSID
Перейдите в Settings → Wireless Networks.

Выберите гостевую SSID или создайте новую.

В разделе Security выберите RADIUS и укажите созданный профиль.

Включите RADIUS Accounting.

Примените изменения.

3.3. Проверка
Убедитесь, что в панели администратора устройство отображается как online. Подключитесь к гостевой сети – авторизация должна происходить через платформу.
