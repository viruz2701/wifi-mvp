# Настройка pfSense с captive portal для работы с WiFi Auth Platform

## 1. Установка и настройка Captive Portal
В pfSense перейдите в `Services` -> `Captive Portal`.

1. Нажмите `Add` для создания нового портала.
2. Задайте имя (например, `guest_wifi`).
3. Выберите интерфейс, на котором будет работать портал (например, `OPT1` для гостевой сети).
4. Настройте параметры:
   - **Authentication**: выберите `RADIUS Authentication`.
   - **RADIUS server**: добавьте ваш сервер (IP, секрет).
   - **RADIUS accounting**: включите, если нужен учёт трафика.
5. В разделе **Portal page** можно оставить страницу по умолчанию или загрузить свою. Но для работы с платформой лучше оставить встроенную, которая будет отправлять логин/пароль на RADIUS.

## 2. Настройка RADIUS-клиента
В `System` -> `User Manager` -> `Authentication Servers` добавьте RADIUS-сервер:
- **IP address**: ваш сервер.
- **Shared secret**: секретный ключ.
- **Protocol**: MSCHAPv2 (обычно).

## 3. Настройка правил файрвола
Убедитесь, что трафик к RADIUS-серверу разрешён:
- Добавьте правило в интерфейсе, где находится сервер (например, WAN или LAN), разрешающее исходящие UDP на порты 1812 и 1813 к IP сервера.

## 4. Добавление устройства в платформу
Создайте NAS-устройство типа `pfsense` (если такого типа нет, используйте `generic` или `mikrotik` с соответствующими атрибутами). Укажите IP-адрес pfSense и секретный ключ.

## 5. Проверка
Подключитесь к гостевой сети, откройте браузер – должна появиться страница портала. Введите номер телефона (как логин) и код (как пароль) – после успешной авторизации доступ должен открыться.

## 6. Отладка
- Логи Captive Portal: `Status` -> `System Logs` -> `Captive Portal`.
- Проверьте, что pfSense отправляет RADIUS-запросы (можно увидеть в логах сервера).
- Убедитесь, что в настройках RADIUS-сервера правильно указан secret.
