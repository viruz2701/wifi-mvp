# Архитектура тарифных планов и приоритетной скорости

## Модели
- `TariffPlan` – тарифный план
- `venue_tariff` – связующая таблица (какие тарифы доступны на площадке)
- `UserProfile` – поля `current_tariff_id` и `tariff_expires_at` для активного тарифа

## RADIUS-авторизация
При успешной авторизации возвращаются атрибуты WISPr для ограничения скорости, если у пользователя активен тариф.
