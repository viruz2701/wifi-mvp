## Управление площадками (администратор)

Площадка (Venue) — это место, где установлено Wi-Fi оборудование (кафе, гостиница, офис).

### Добавление площадки
1. Перейдите в раздел «Площадки».
2. Нажмите кнопку «Добавить».
3. Заполните поля:
   - **Название** – обязательное.
   - **Домен** – уникальное доменное имя, по которому будет доступен портал авторизации (например, `cafe.example.com`).
   - **Адрес, телефон, email** – необязательные контактные данные.
   - **Активна** – если снять галочку, площадка временно отключается.
   - **HTTPS** – включить поддержку SSL (если настроен сертификат).
4. Нажмите «Сохранить».

### Редактирование и удаление
- Используйте иконки карандаша (редактировать) и корзины (удалить) в списке площадок.
- Удаление происходит мягко (запись помечается как удалённая, но данные сохраняются в базе).

## Управление NAS-устройствами

NAS-устройство (точка доступа, роутер) – оборудование, которое подключается к платформе и отправляет RADIUS-запросы.

### Добавление устройства
1. Перейдите в раздел «NAS-устройства».
2. Нажмите «Добавить».
3. Выберите площадку, к которой относится устройство.
4. Укажите **тип** (MikroTik, OpenWRT, Ubiquiti).
5. Заполните **IP-адрес**, **RADIUS secret** (секретный ключ, который будет использоваться в настройках роутера).
6. При необходимости укажите **API-учётные данные** для удалённого управления (для MikroTik – имя пользователя и пароль RouterOS, для OpenWRT – SSH-логин/пароль, для Ubiquiti – данные UniFi Controller).
7. Если устройство будет подключаться через WireGuard, укажите **WireGuard public key** и опционально **WireGuard IP**.
8. Нажмите «Сохранить».

### Статус устройства
В списке устройств отображается статус доступности:
- 🟢 Online – устройство отвечает на проверку (TCP-порт или ping).
- 🔴 Offline – устройство недоступно.
Время последней проверки также показывается.

### Действия на устройстве (для администратора)
На странице детального просмотра или через иконки в списке доступны:
- **Перезагрузить** – отправить команду перезагрузки (поддерживается для MikroTik и OpenWRT).
- **Сбросить все сессии** – принудительно завершить все активные сессии клиентов на устройстве.

## Шаблоны портала авторизации

Платформа позволяет настраивать внешний вид страниц, которые видит пользователь при подключении к Wi-Fi.

### Типы шаблонов
- **auth** – страница запроса номера телефона.
- **welcome** – страница приветствия после успешной авторизации (с баннером).
- **error** – страница ошибки (например, при неверном коде).

### Создание шаблона
1. Перейдите в раздел «Шаблоны портала».
2. Нажмите «Добавить».
3. Выберите площадку и тип шаблона.
4. В поле **HTML-код** введите разметку страницы. Можно использовать следующие макросы, которые будут заменены реальными значениями:
   - `$(phone)` – введённый номер телефона.
   - `$(mac)` – MAC-адрес устройства клиента.
   - `$(dst)` – целевой URL, на который клиент хотел перейти.
   - `$(error)` – сообщение об ошибке.
   - `$(banner_url)` – URL баннера для показа.
   - `$(venue_name)` – название площадки.
   - `$(code)` – код подтверждения (используется только на странице ввода кода).
5. При необходимости загрузите CSS, JavaScript или изображения через вкладку **Файлы**.
6. Нажмите «Сохранить».

### Предпросмотр
Нажмите на иконку глаза рядом с шаблоном, чтобы увидеть, как он будет выглядеть с тестовыми данными.

## Баннеры и реклама

Баннеры отображаются на странице приветствия после авторизации. Можно настроить несколько баннеров для одной площадки и отслеживать клики.

### Добавление баннера
1. Перейдите в раздел «Баннеры».
2. Выберите площадку.
3. Нажмите «Добавить».
4. Укажите **URL перехода** – ссылку, на которую попадёт пользователь при клике.
5. После сохранения баннера загрузите изображение через кнопку «Загрузить» в списке.
6. Отметьте **Активен**, чтобы баннер начал показываться.

### Учёт показов и кликов
- При загрузке страницы приветствия счётчик **Показы** увеличивается автоматически.
- При клике на баннер пользователь перенаправляется на целевой URL, а счётчик **Клики** увеличивается асинхронно (через Celery).

## Профили Wi-Fi пользователей

В этом разделе отображаются все клиенты, когда-либо подключавшиеся к Wi-Fi через платформу.

### Фильтры
Вы можете фильтровать список по:
- **Площадке** (для администратора – все площадки, для владельца – только его).
- **MAC-адресу** – частичное совпадение.
- **Телефону** – точное совпадение.
- **Статусу блокировки** – заблокирован/не заблокирован.

### Действия с профилем
- Нажмите на строку профиля, чтобы открыть детальную информацию.
- Кнопка **Редактировать** позволяет изменить флаги:
  - **Заблокирован** – клиент не сможет авторизоваться.
  - **VIP** – приоритетный доступ (можно использовать для безусловного пропуска).

## Отчёты и аналитика

Раздел доступен администраторам и маркетологам. Доступны четыре типа отчётов:

1. **Активность** – график количества уникальных пользователей и сессий по дням. Можно выбрать период и площадку.
2. **Топ пользователей** – список клиентов с наибольшим объёмом трафика или числом сессий.
3. **Устройства** – распределение по производителям (Apple, Samsung и др.) на основе OUI MAC-адреса.
4. **SMS** – количество отправленных и подтверждённых кодов за период.

Каждый отчёт можно выгрузить в формате CSV.

## Управление администраторами

Только суперпользователь может создавать и редактировать учётные записи персонала.

### Роли пользователей
- **admin** – полный доступ ко всем функциям.
- **venue_owner** – доступ только к своей площадке (может видеть NAS-устройства, профили, отчёты).
- **marketing** – доступ к баннерам и отчётам.
- **support** – просмотр профилей и логов (без редактирования).

### Создание пользователя
1. Перейдите в раздел «Администраторы».
2. Нажмите «Добавить».
3. Укажите email, пароль, выберите роль.
4. Для роли `venue_owner` необходимо выбрать площадку.
5. Нажмите «Сохранить».

## Дашборд для владельца площадки

Владелец площадки (venue_owner) видит специальную страницу «Дашборд» с ключевыми метриками за выбранный период (сегодня, неделя, месяц):
- Количество уникальных пользователей.
- Количество новых сессий.
- Объём трафика (в МБ).
- Количество отправленных и подтверждённых SMS.

Также на дашборде отображается график активности за последние 30 дней.

## Экспорт данных

Для владельцев площадок и администраторов доступна страница «Мои данные», где можно просматривать логи авторизаций (события `auth_confirm` и `session_start`) с фильтрацией по MAC, телефону и дате. Кнопка **CSV** или **JSON** позволяет выгрузить отфильтрованные данные.

Также через отдельные эндпоинты API можно экспортировать сессии и логи (см. документацию API).

## Мониторинг оборудования (NAS)

В разделе «NAS-устройства» отображается статус каждого устройства (онлайн/оффлайн) на основе периодических проверок. При клике на устройство можно увидеть историю изменения статуса и детали последней проверки.

Для администраторов доступна отдельная страница **WireGuard Peers**, где можно управлять VPN-пирами, вручную добавлять или удалять их, а также редактировать параметры (Allowed IPs, endpoint).

---

## Дополнительная информация

- **Безопасность**: Все пароли администраторов хранятся в зашифрованном виде, RADIUS-секреты шифруются симметрично.
- **Логирование действий**: Критичные действия администраторов (создание/удаление объектов, изменение прав) записываются в таблицу `audit_logs` для последующего аудита.
- **Поддержка**: При возникновении проблем обращайтесь к системному администратору или разработчикам.
